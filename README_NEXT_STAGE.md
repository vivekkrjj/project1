# Bhumi Nursing College — Digital Library Next Stage

This build adds:
- Course-locked Digital Library (ANM/GNM/B.Sc Nursing + All Nursing)
- Private Supabase Storage bucket support for admin PDF/document uploads
- Temporary signed download links for approved students
- Course-locked online MCQ practice tests
- Student test history and percentage results
- Admin MCQ question-bank management
- Supabase migration: `supabase/QUIZ_AND_LIBRARY_FILES.sql`

Only upload/distribute files that the college owns or has permission to distribute. Third-party learning material should use official/open-access links.
